# Baggy Denim Jeans

股上を深くとった独特なワイドシルエットが特徴のバギーデニムです。

様々な加工を施し、奥行きのあるデニムの表情に仕上げています。ベルトループから縫製箇所まで細かく入るダメージ感も魅力。ウエスト内側はドローコードの仕様。デニム特有の経年変化を愉しんでいただけます。オールシーズンでご愛用いただけるアイテムとなっております。

## 生地について

### 12OZ VINTAGE DENIM

色により別々のデニムを使用。インディゴは特濃ロープインディゴ染色、ブラック・グレーは硫化染ロープ染色。旧式力織機でゆっくりと時間をかけて織られたヴィンテージの表情が特徴のデニム生地。タテのムラ糸はシャープな形状で、エイジングにより、リアルな色落ち感が出ます。グレーは8/-×7/-の珍しい規格。全色12オンスの中肉厚ながら、柔らかいクタッとした風合いが特徴。
